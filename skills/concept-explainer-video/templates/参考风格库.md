### 去 AI 味的通用策略（百试百灵）

- **手动降精度**：提示词里写 `not perfect, handmade feel, slightly uneven edges, avoids symmetrical AI-generated look`
- **避开高危词**：`trending on artstation`/`masterpiece`/`cinematic`/`ultra detailed`——写了就AI腔
- **文字加语气**：`designed by a human graphic designer, not an AI` 或 `indie zine aesthetic` 有效

### 风格不强的要求

乐高除外不行；系列片可以交替用多种风格防止审美疲劳，但不要强行杂糅。

### 已验证的风格配方（按 AI 味残留排序）

**佳：有明显人工痕迹，可用手作位置角色参考**
```
construction paper collage style, paper cutout shapes, slightly uneven hand-cut edges, 
photographed on table with natural shadows, studio photo of physical craft, 
material textures visible, not perfect geometry, 
explainer diagram: [内容描述]
```

**较好：印刷品感觉，适合海报感镜头**
```
risograph print style, two-color overlap misregistration, grainy texture, 
flat printed look, off-registration, visible dot pattern, 
vintage printmaking feel, not digital smooth
```

**较好：黑板粉笔感**
```
chalk drawing on blackboard, imperfect chalk lines, dust smudges, 
eraser marks, classroom sketch feel, hand-drawn uneven strokes, 
matte texture
```

**中：像素风小人（角色专用）**
```
pixel art, 8px pixel grid, flat shading, limited palette 12-16 colors, 
no anti-aliasing, no gradient, hard edges, game sprite style, 
transparent background
```

**其他已验证但较浓 AI 味（需结构调整）：3D render / 线框蓝图 / 水墨 / ASCII / 水彩 / 油印蜡纸**

## 从帧分析里提取的「共同配方」（7/8 支都符合）

这 8 支片子的视觉共性，就是我们自己片子应该符合的默认标准：

1. **底色一律深**：深空蓝/深灰黑/深炭黑，90% 是暗色背景。
2. **一个亮色当刀**：一个高亮点缀色（亮青/电光蓝/金黄/橙）在暗底上跳，用来牵住注意力。
3. **元素都分层**：每一个元素（图标、文字、图形、人物）都是独立图层，单帧就能看出来，这样动画才好做。
4. **描边 + 微光效**：绝大多数元素有清晰描边或轻微发光。
5. **粒子只出现在概念高潮处**：不是全程粒子，用到才用。
6. **图形高度几何化**：圆、矩形、线、箭头、轨道——全是可以用几何元素描述的东西。
7. **构图偏中**：没有一个视频是斜构图或大量不对称的，大量居中构图。

**这 7 条可以当成我们的"任何镜头都要过一遍"的默认检查项。**

## 对应到我们的制作流程：每条怎么落地

| 配方规则 | 我们的落地方法 |
|---|---|
| 深色背景 | 默认 #0A0F1F（更接近硬件茶谈/新石器公园，别用之前那个 1B2A4A 明亮深蓝了） |
| 亮色点睛 | 从 [电光蓝#00D4FF / 亮青#00FFFF / 金黄#FFB800 / 暖橙#E8A33D] 四选一，不轮着用，一支片子只挑一个 |
| 元素分层 | AI 生成素材时就要求分层：给提示词加 `separate clean layers, isolated elements` |
| 描边光效 | 后期在剪辑里加外发光/描边，素材上不必强求 |
| 粒子省着用 | 只有转场和核心概念揭晓时用 |
| 几何化 | AI 生图提示词里写 `geometric shapes only, circular or rectangular, no organic curves` |
| 居中构图 | 生图提示词 `centered composition, symmetric layout` |
